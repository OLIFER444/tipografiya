# tipografiya-pwa

Страница-обёртка вокруг веб-приложения Google Apps Script (учёт выручки типографии).
Публикуется на GitHub Pages: https://olifer444.github.io/tipografiya/

Зачем: убирает постоянный баннер «Это приложение создано пользователем Google Apps Script»
и даёт свою иконку при установке как PWA.

## Структура

- `/` — страница выбора. Не устанавливается (манифеста нет намеренно: его scope
  накрывал бы подпапки и перехватывал ссылки на них). Старые ссылки вида
  `?app=nk` перенаправляет на соответствующую папку.
- `/ng/`, `/nk/`, `/admin/` — по приложению на офис. У каждого свой `manifest.json`
  со своим `start_url` и именем, офис зашит в `index.html`.
- `icon-192.png`, `icon-512.png` — общие иконки, прозрачные.

## Почему по папке на офис

Раньше офис передавался параметром `?app=`, а манифест был один со `start_url: "./"`.
Установленное приложение запускается со своего `start_url`, параметр при этом теряется —
и любая ссылка открывала Новогиреево. Один манифест = один офис, поэтому папки разные.

## Правила

- `purpose` иконок — только `any`. `maskable` несовместим с прозрачностью:
  система обрежет иконку по своей маске и подставит свою подложку.
- URL деплоя Apps Script (`BASE`) захардкожен в каждом `<офис>/index.html` —
  при смене деплоя правится во всех трёх.
- Смена иконки видна только после полной переустановки PWA (удалить через
  `chrome://apps`, а не ярлык), с очисткой данных сайта.
